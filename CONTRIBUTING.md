# Contributing to tidl

Thank you for your interest in contributing to tidl!

## Development Setup

1. Install Nix with flakes enabled
2. Clone the repository
3. Enter the dev environment: `nix develop`

## Code Style

- Follow standard Rust conventions (rustfmt)
- Write tests for new functionality
- Update documentation as needed

## Pull Request Process

1. Fork the repository
2. Create a feature branch
3. Make your changes with clear commit messages
4. Ensure tests pass: `cargo test --workspace`
5. Submit a pull request

## Areas for Contribution

- Additional markdown source implementations
- CalDAV protocol improvements
- UI enhancements
- Documentation
- Bug fixes
